# TicTacToeAI v0.1

일반·궁극 틱택토를 플레이하고 인공지능의 판단을 관찰하는 한국어 웹 실험실입니다.

배포 주소: https://oyueo-mm.github.io/TicTacToeAI/

## 실행 및 검증

Node.js 24 이상을 권장합니다.

```sh
npm ci
npm run dev
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run preview
```

개발 주소는 `http://127.0.0.1:5173/TicTacToeAI/`입니다. React 19, TypeScript, Vite, Tailwind CSS 4, Lucide 아이콘, Vitest, Playwright를 사용합니다. 게임 규칙과 학습 엔진은 React에 의존하지 않습니다.

## 화면과 기능

- **홈**: 좌측 제목·대국 시작 버튼과 우측 실제 엔진 자동 대국. 일반·궁극 전환, 재생 일시정지, 숨겨진 탭에서 정지, reduced-motion 대응. 휴리스틱과 무작위 정책을 섞어 여러 대국을 보여줍니다.
- **대국실**: 사람 대 사람 / 사람 대 AI / AI 대 AI, 선후공 선택, 속도, 일시정지, 재시작, 착수 취소, 착수별 기록과 후보 평가. 좌우 패널은 독립적으로 접고 펼칠 수 있으며, 접힌 공간만큼 중앙 게임판이 커집니다. 게임·설정·패널 상태를 새로고침 후 복원합니다. 완료 대국은 오른쪽 기록 패널에서 선택해 재생합니다.
- **모델**: 기존 localStorage Q-table과 v0.1 저장 모델을 유지합니다. 대국실·Arena에서 Q-learning을 선택하면 모델 선택·JSON 불러오기를 사용할 수 있습니다. 적용한 모델은 두 화면에 공통으로 사용되며 선택 상태도 저장합니다. 가져온 JSON은 기존 게임·버전·Q-value 검증을 통과해야 합니다.
- **AI Arena**: 알고리즘별 자동 대국, 선후공 교대, 단일·연속·고속 대국, 일시정지, 승무패 통계, 결과 필터와 착수 재생.
- **반응형 UI**: 접이식 사이드바, 모바일 드로어, 키보드 포커스와 Escape, 블루 X와 민트 O, 순백색 배경과 하단 툴바.

내비게이션은 **홈 · 대국실 · AI Arena** 3개입니다. AI 학습·학습 분석 페이지와 관련 진입 UI는 제거했습니다. Q-learning 학습 엔진과 모델 형식은 변경하지 않았으며 단위 테스트로 보존합니다. 기존 `training`, `models`, `match`, `match-settings`, `records` 데이터는 삭제하지 않습니다.

좌우 패널은 DOM과 React 상태를 유지하면서 CSS Grid 열 너비를 0으로 전환합니다. 접혀 있는 패널은 `inert`로 포커스에서 제외하고, 게임판 옆 아이콘으로 다시 열 수 있습니다. 게임판은 가용 너비·화면 높이에 맞춰 정사각형을 유지합니다. 모바일은 게임판 다음에 패널을 배치하며 접기·펼치기 시 해당 버튼으로 포커스를 옮깁니다. 패널 전환은 게임이나 Worker 탐색을 다시 시작하지 않습니다.

## 게임 규칙

**일반**: 3×3 판에 X와 O가 교대로 착수합니다. 가로·세로·대각선 3목이면 승리하고, 판이 가득 차면 무승부입니다.

**궁극**: 9개의 3×3 작은 판(81칸)을 사용합니다. 작은 판 안에서 둔 위치가 상대가 다음에 둘 작은 판을 지정합니다. 첫 수나 지정된 판이 종료된 경우 진행 중인 판에 자유 착수합니다. 작은 판 3목은 그 판을 점령하며, 큰 판에서 점령한 판 3개를 연결해야 전체 승리입니다. 승리·무승부로 끝난 작은 판에는 둘 수 없습니다. 큰 판에 승자가 없고 모든 작은 판이 종료되면 무승부입니다. 작은 판의 무승부는 큰 판의 승리 표식으로 계산하지 않습니다.

## AI와 학습

| 알고리즘   | 일반           | 궁극                   | 표시하는 실제 결과                    |
| ---------- | -------------- | ---------------------- | ------------------------------------- |
| Random     | 지원           | 지원                   | 무작위 합법 착수                      |
| Rule-based | 승리·방어·위치 | 작은 판·큰 판 휴리스틱 | 후보 점수                             |
| Minimax    | 완전 탐색      | 미지원                 | 결정적 평가값·노드·시간               |
| Alpha-Beta | 완전 탐색      | 깊이 1~4 제한          | 후보별 정확한 평가·가지치기 노드·시간 |
| Q-learning | 지원           | 미지원                 | 상태별 Q-value                        |
| MCTS       | UI 미제공      | 지원                   | 후보 방문 수·추정 승점률·반복 진행    |

Minimax와 Alpha-Beta는 일반 틱택토에서 같은 최적 평가를 반환합니다. 후보를 각각 완전한 alpha/beta 범위로 평가하므로 모든 후보의 점수가 정확합니다. 일반 판의 평가 0은 최적 대국 무승부, 양수는 강제 승리, 음수는 강제 패배입니다. 점수는 확률이 아닙니다. 궁극 판은 깊이 제한 휴리스틱이며 최적 승패를 보장하지 않습니다.

MCTS는 UCT selection, expansion, 무작위 rollout, backpropagation을 수행합니다. 노드 보상은 루트 플레이어 기준으로 유지하고 상대 차례의 selection에서는 부호를 반전합니다. 승 1, 무 0.5, 패 0 기준의 **추정 승점률**을 표시하며 가장 많이 방문한 수를 선택합니다. 이 수치는 보장된 승리 확률이 아닙니다.

Q-table의 키는 현재 플레이어 기준 `1 / 2 / -` 상태이며 행동은 0~8입니다. ε-greedy로 탐험하고, 같은 플레이어의 다음 차례를 하나의 전이로 사용합니다.

```text
Q(s,a) ← Q(s,a) + α [r + γ max Q(s',a') − Q(s,a)]
```

보존된 학습 엔진에서 종료 전이의 다음 상태 값은 0입니다. 보상은 승리 +1, 무승부 +0.2, 패배 −1입니다. Self-play에서는 각 플레이어의 전이를 독립적으로 갱신합니다. 탐험률은 에피소드마다 `ε × decay^index`로 줄어듭니다. 현재 UI는 저장된 Q-table을 사용하는 대국만 제공합니다.

고비용 AI 탐색은 기존 Web Worker에서 실행합니다. 게임 규칙, 탐색 알고리즘, Q-learning 보상·업데이트 계산은 UI 간소화 작업에서 변경하지 않았습니다.

## 구조

```text
src/core/         공통 게임 규칙·상태 전이와 테스트
src/ai/           Random, 휴리스틱, Minimax, Alpha-Beta, MCTS
src/training/     Q-learning 엔진과 테스트
src/workers/      계산 Worker와 취소 가능한 클라이언트
src/storage/      모델 검증, 브라우저 저장, JSON 다운로드
src/components/   공통 보드·입력·패널
src/pages/        홈, 대국실, Arena
src/styles/       디자인 시스템과 반응형 레이아웃
tests/            데스크톱·모바일 Playwright 시나리오
```

참고 프로젝트 [RL-Playground](https://github.com/oyueo-mm/RL-Playground), [NeuralCanvas](https://github.com/oyueo-mm/NeuralCanvas)의 홈·메뉴·학습 속도·패널 구조를 읽기 전용으로 분석했습니다. 해당 저장소는 수정하지 않았습니다.

## 데이터와 한계

- 서버 계정·클라우드 동기화 없이 해당 브라우저에 저장합니다. 브라우저 데이터를 삭제하면 사라집니다. 저장 용량 부족은 UI에 알립니다.
- 완료 대국은 최근 100개를 유지합니다. 기존 학습 데이터는 그대로 보관하며 현재 UI에서는 추가 학습하지 않습니다.
- 궁극 AI의 탐색량·깊이는 제한됩니다. MCTS rollout은 무작위 정책이므로 적은 반복에서 약할 수 있습니다.
- Arena 고속 모드는 착수 대기 시간을 제거합니다. 탐색 자체와 Worker 시작 시간은 여전히 필요합니다.
- DQN·AlphaZero, 궁극 Q-learning, 서버 저장, 탐색 트리 전체 시각화, 궁극 보드의 별도 확대 도구는 미구현입니다. 모바일에서도 81칸을 표시하며 브라우저 확대를 사용할 수 있습니다.
- 대국 설정을 바꾸면 현재 상태에 새 정책이 적용됩니다. 게임 모드·선후공 변경과 새 게임은 판을 초기화합니다.

## 배포

Vite base는 `/TicTacToeAI/`입니다. `main` 푸시 시 `.github/workflows/deploy.yml`이 단위 테스트, 데스크톱·모바일 Playwright, 타입 검사·빌드를 모두 통과한 후 GitHub Pages에 배포합니다. PR은 검증만 수행합니다.

저장소 관리 권한이 있는 로컬 환경에서는 `node scripts/github.mjs status`로 Actions와 Pages 상태를 확인할 수 있습니다. 스크립트는 Git credential helper의 인증을 메모리에서만 사용하며 비밀값을 출력하거나 파일에 저장하지 않습니다.

향후 로드맵: IndexedDB 기반 대규모 모델 저장, 학습 세션별 비교, MCTS 트리 상세 시각화, 궁극 보드 확대, DQN 및 AlphaZero 실험.
